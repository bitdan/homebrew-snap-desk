# Snap Desk tap / bucket

[Snap Desk](https://github.com/bitdan/snap-desk) 的 Homebrew tap 与 Scoop bucket。清单由 Snap Desk 的发布流水线在每个正式版发布后自动更新，请勿手动修改。

The Homebrew tap and Scoop bucket for [Snap Desk](https://github.com/bitdan/snap-desk). Manifests are updated automatically by the Snap Desk release pipeline after each stable release; do not edit them by hand.

## macOS（Homebrew，Apple 芯片）

```bash
brew install --cask bitdan/snap-desk/snap-desk
```

## Windows（Scoop）

```powershell
scoop bucket add snap-desk https://github.com/bitdan/homebrew-snap-desk
scoop install snap-desk
```
